# Runtime credentials

Supply these environment variables through the deployment secret store before starting the application:

- `SMTP_PASSWORD`
- `DB_PASSWORD`

Property names are unchanged. No credential defaults are provided.
Previously committed values remain in Git history and may exist in upstream forks.
Verify ownership and revoke/rotate the original credentials separately; this source change does not revoke them.
No live deployment or external login was performed as part of this change.
